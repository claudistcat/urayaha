# うさぎ語 早見表

書きながら手元に置くための対応表です。説明は [言語ガイド](language-guide.md) に
あります。

`！`/`？` は `!`/`?` に正規化されるので、全角でも半角でも同じ語になります。
一方 `～ ー … ・ ッ ァ ィ ゥ ェ ォ ャ ュ ョ` は正規化されないので、
書いたとおりに区別されます。

---

## 予約語

| 書く | 意味 |
|---|---|
| `ヤハ` | 変数宣言 |
| `ヤハ！` | 定数宣言 |
| `フゥン` | 関数宣言・無名関数 |
| `ハァ？` | if |
| `ウラ` | else |
| `ウ～ラ～` | while(`～` は全角チルダ) |
| `ツツウラウラ` | foreach |
| `ヤーッ` | ブロック開始 |
| `ハァッ` | ブロック終了 |
| `ハァーッ` | return |
| `ムリッ` | break |
| `イヤッ` | continue |
| `イヤッハー` | 標準出力 |
| `イヤッハー…` | 標準出力(改行なし) |
| `ヤッハーヤーハー` | 公開修飾子 |
| `ヤー` | true |
| `イヤ` | false |
| `……` | null(三点リーダ 2 つ) |
| `コレ` | メソッド内の自分自身 |

### ハチワレ語(うさぎ語で足りないところ)

| 書く | 意味 |
|---|---|
| `なんとかなれーッ` | try |
| `なんとかなれーッ！` | Result の中身を取り出す |
| `ダメだった…` | catch |
| `これって…` | import |
| `こういうこと？` | 型宣言 |
| `もしかして` | match |
| `ってこと？` | case |
| `じゃないってこと？` | default |
| `ワァーッ！` | 例外を投げる |
| `ヤッター` | Result の成功 |
| `ワァ…` | Result の失敗 |

## 数字

数値リテラルは必ず `ン・` で始めます。中身は 4 進です。

| 文字 | 値 |
|---|---|
| `ン` | 0 |
| `プ` | 1 |
| `ル` | 2 |
| `ャ` | 3 |

| 書く | 10 進 |
|---|--:|
| `ン・ン` | 0 |
| `ン・プ` | 1 |
| `ン・ル` | 2 |
| `ン・ャ` | 3 |
| `ン・プン` | 4 |
| `ン・ププ` | 5 |
| `ン・プル` | 6 |
| `ン・プャ` | 7 |
| `ン・ルン` | 8 |
| `ン・ルプ` | 9 |
| `ン・ルル` | 10 |
| `ン・ルャ` | 11 |
| `ン・ャン` | 12 |
| `ン・ャプ` | 13 |
| `ン・ャル` | 14 |
| `ン・ャャ` | 15 |
| `ン・プンン` | 16 |
| `ン・ププン` | 20 |
| `ン・プルャ` | 27 |
| `ン・プャプン` | 100 |

`ン・` の無い `プルャ` は識別子です。

## 型

| 書く | 型 |
|---|---|
| `プルッ` | Int |
| `プルァッ` | Float |
| `ヤハ？ッ` | Bool |
| `ワァッ` | String |
| `ムレッ` | List |
| `ウララッ` | Map |
| `ナンカッ` | Any |
| `ナシッ` | Void |
| `ヤッタッ` | Result |

ジェネリックは `ムレッ<プルッ>`、Optional は `プルッ?` です。

## 演算子

演算子はうさぎ語にしません。実用性のための明示的な設計判断です。

```
+  -  *  /  %
==  !=  <  >  <=  >=
&&  ||  !
=  +=  -=  *=  /=
??  ?.
|>
->  =>  ...
```

## 共通操作語

標準ライブラリと組み込み型のメソッドは、この 6 語を使い回します。
意味はモジュールごとに文脈で決まります。

| 語 | 意味 |
|---|---|
| `フゥン` | 取得・読込・変換 |
| `ヤハ` | 設定・追加・書込 |
| `ハァ？` | 確認・問い合わせ |
| `イヤッ` | 削除・破棄 |
| `イヤッハー` | 文字列化・外部化・出力 |
| `ン？` | 件数・サイズ |

たとえば `フゥン` は、ファイルなら読込、JSON なら parse、HTTP なら GET、
List なら map、環境変数なら取得です。

## 組み込み型のメソッド

### List

| 書く | すること |
|---|---|
| `.ン？()` | 要素数 |
| `.ヤハ(値)` | 末尾に足す |
| `.イヤッ(値)` | 最初の 1 つを消す |
| `.フゥン(関数)` | map |
| `.ハァ？(関数)` | filter |
| `.ウラ(関数, 初期値)` | reduce |
| `.ツナグ(区切り)` | 文字列に連結 |
| `.ナラベ()` | 並べ替え |
| `.アル？(値)` | 含むか |

### Map

| 書く | すること |
|---|---|
| `.ン？()` | 件数 |
| `.ハァ？(鍵)` | あるか |
| `.ヤハ(鍵, 値)` | 入れる |
| `.イヤッ(鍵)` | 消す |
| `.カギ()` | 鍵の一覧 |

### String

| 書く | すること |
|---|---|
| `.ン？()` | 文字数 |
| `.ワケ(区切り)` | 分ける |
| `.ハァ？(部分)` | 含むか |
| `.ツナグ(List)` | 自分を区切りにして連結 |

### Result

| 書く | すること |
|---|---|
| `.ヤッタ？()` | 成功したか |
| `.フゥン()` | 中身を取り出す(失敗なら失敗理由) |
| `.なんとかなれーッ！()` | 中身を取り出す。失敗なら例外を投げる |

## 命名の慣習

| 用途 | 例 |
|---|---|
| ローカル変数 | `ヤハァ` `ヤハッ` `ヤハァッ` `ヤハー` |
| 関数 | `フゥンッ` `フゥンァ` `フゥーン` `フゥン？` |
| 定数 | `プルャ` `プルャッ` `プルャァ` |
| 型 | `ウララ` `ウラァ` `ウララァ` |

名前から意味は読み取れません。定義位置・型・引数・コメントから理解します。
これがこの言語のジョークの中心です。読みづらいときは
`urayaha dump --types` を使ってください。
