# URAYAHA 言語ガイド

このドキュメントを上から読めば、URAYAHA でプログラムが書けるようになります。
リファレンスではなく手引きなので、実際に動かしながら読むことを想定しています。

標準ライブラリの全メンバは [stdlib.md](stdlib.md)、コマンドの詳細は
[cli.md](cli.md)、エラーの一覧は [errors.md](errors.md) にあります。
うさぎ語と意味の対応だけ知りたいときは [vocabulary.md](vocabulary.md) が早いです。

## 1. 最初のプログラム

`hello.ura` を作ります。

```
イヤッハー("ワァ……！")
```

走らせます。

```bash
urayaha run hello.ura
```

```
ワァ……！
```

`イヤッハー` が標準出力です。改行したくないときは `イヤッハー…` を使います。

```
イヤッハー…("ヤハ")
イヤッハー…("ヤハ")
イヤッハー("ヤーッ！")
```

```
ヤハヤハヤーッ！
```

## 2. ソースファイル

| 項目 | 値 |
|---|---|
| 拡張子 | `.ura` |
| 文字コード | UTF-8 |
| 改行 | LF 推奨 |

コメントは 2 種類です。コメントの中では普通の日本語も英語も自由に書けます。

```
// 1 行コメント

/*
    複数行コメント
*/
```

文の終わりにセミコロンは要りません。改行が文の区切りです。

```
ヤハ ヤハァ = ン・プ
ヤハ ヤハッ = ン・ル
```

1 行に複数の文を詰めるときだけ `;` が使えますが、推奨しません。

**語と語のあいだには空白が必要です。** すべてカタカナなので、空白が無いと
どこで語が切れるのか決まりません。`ウラウラ` は 1 つの識別子として読まれ、
`ウラ ウラ` が else 2 つになります。

式は複数行に折り返せます。

```
ヤハ ヤハァ =
    フゥンッ(ン・プ) +
    フゥンッ(ン・ル)
```

## 3. 数値

数値リテラルは **必ず `ン・` で始めます**。中身は 4 進数です。

| 文字 | 値 |
|---|---|
| `ン` | 0 |
| `プ` | 1 |
| `ル` | 2 |
| `ャ` | 3 |

```
ン・ン       // 0
ン・プ       // 1
ン・ャ       // 3
ン・プン     // 4
ン・ププ     // 5
ン・ルル     // 10
ン・プルャ   // 1×16 + 2×4 + 3 = 27
```

**`ン・` を付けない `プルャ` は常に識別子です。** これが重要な点で、名前と数が
字句のレベルで混ざりません。次のコードは合法です。

```
ヤハ プルャ = ン・プルャ      // 変数 プルャ に 27 を入れる
```

小数も 4 進です。小数点以下の 1 桁目が 1/4 の位になります。

```
ン・プ.ル       // 1 + 2/4 = 1.5
ン・ン.プ       // 0.25
```

負数は単項マイナスです。

```
-ン・プ
```

読むのがつらいときは `--human-number` を付けると 10 進で表示されます。

```bash
urayaha run main.ura --human-number
```

## 4. 文字列

`"..."` で囲みます。中身は普通の自然言語で構いません。UI 文字列までうさぎ語に
する必要はありません。

```
イヤッハー("処理が完了しました")
```

エスケープは `\n` `\t` `\r` `\"` `\\` `\$` が使えます。

`${...}` で式を埋め込めます。中には任意の式が書けます。

```
ヤハ ヤハァ = ン・ャ
イヤッハー("うさぎが ${ヤハァ} 匹")
イヤッハー("たすと ${ヤハァ + ン・プ}")
```

文字列の中身は正規化されません。`"ワァ！"` の `！` は全角のまま出ます。

```
ヤー        // true
イヤ        // false
……          // null(三点リーダ 2 つ)
```

```
ヤハ ヤハァ = ヤー
ヤハ ヤハッ: プルッ? = ……

ハァ？ ヤハッ == …… ヤーッ
    イヤッハー("ワァ……")
ハァッ
```

## 6. 変数と定数

変数は `ヤハ` で宣言します。デフォルトで書き換えられます。

```
ヤハ ヤハァ = ン・プル
ヤハァ = ン・プャ
```

定数は `ヤハ！` です。書き換えるとコンパイルエラー(E1003)になります。

```
ヤハ！ プルャ = ン・ル
```

スコープはレキシカルです。ブロックの外からは見えません。

```
ハァ？ ヤー ヤーッ
    ヤハ ヤハッ = ン・ル
ハァッ
// ここでは ヤハッ は使えない
```

外側と同じ名前を宣言し直すと警告(W1002)が出ますが、エラーではありません。
使わなかった変数にも警告(W1001)が出ます。`_` で始まる名前は警告されません。

## 7. 型

静的型付けですが、型推論があるので普通は書きません。

```
ヤハ ヤハァ = ン・プ        // プルッ(Int)と推論される
```

明示したいときは `:` のあとに書きます。

| 型 | 表記 |
|---|---|
| Int | `プルッ` |
| Float | `プルァッ` |
| Bool | `ヤハ？ッ` |
| String | `ワァッ` |
| List | `ムレッ` |
| Map | `ウララッ` |
| Any | `ナンカッ` |
| Void | `ナシッ` |
| Result | `ヤッタッ` |

型名はすべて `ッ` で終わります。これで数値とも普通の識別子とも混ざりません。

```
ヤハ ヤハァ: プルッ = ン・プ
```

ジェネリックは山括弧です。

```
ヤハ プルャッ: ムレッ<プルッ> = [ン・プ, ン・ル]
ヤハ ウララァ: ウララッ<ワァッ, プルッ> = {"ワァ": ン・プ}
```

Null を許す型には `?` を付けます。

```
ヤハ ヤハァ: プルッ? = ……
```

型変換は明示的に行います。型名がそのまま変換関数です。

```
ヤハ ヤハァ = プルッ("ン・プルャ")     // 27
ヤハ ヤハッ = ワァッ(ン・プルャ)       // "ン・プルャ"
```

> 型検査は「確実に間違っているもの」だけを落とします。推論できないところは
> `ナンカッ` に落として通すので、書きながら試す使い方を邪魔しません。

## 8. 演算子

演算子は記号のままです。ここまでうさぎ語にすると実用性が落ちるので、
意図的にそうしています。

```
算術   +  -  *  /  %
比較   ==  !=  <  >  <=  >=
論理   &&  ||  !
代入   =  +=  -=  *=  /=
Null   ??  ?.
パイプ |>
```

優先順位は高い順に次のとおりです。

```
()  []  .  ?.
!  単項 -
*  /  %
+  -
<  <=  >  >=
==  !=
&&
||
??
|>
=  +=  -=  *=  /=
```

### 整数の割り算

`プルッ` どうしの `/` は 0 方向へ切り捨てます。`%` の符号は割られる側に
合わせます。

```
ン・プルル / ン・プン       // 26 / 4 = 6
-ン・プャ / ン・ル          // -7 / 2 = -3
-ン・プャ % ン・ャ          // -7 % 3 = -1
```

### Null 安全

`?.` は左が `……` ならそこで止まって `……` を返します。
`??` は左が `……` のときだけ右を評価します。

```
ヤハ ヤハァ = ヤハッ?.フゥン()
ヤハ ヤハーッ = ヤハッー ?? ン・プ
```

### パイプ

`|>` は左の値を右の関数に渡します。

```
プルャッ |> フゥンッ |> イヤッハー
```

これは `イヤッハー(フゥンッ(プルャッ))` と同じです。右がすでに呼び出しの形なら、
左の値が第 1 引数として挿し込まれます。

```
ヤハァ |> フゥンッ(ン・ル)      // フゥンッ(ヤハァ, ン・ル)
```

## 9. コレクション

### List

```
ヤハ プルャッ = [ン・プ, ン・ル, ン・ャ]

プルャッ[ン・ン]            // 取り出す
プルャッ[ン・ン] = ン・ププ  // 入れ替える
プルャッ[-ン・プ]           // 後ろから 1 つめ
```

主なメソッドです。

| 書き方 | すること |
|---|---|
| `プルャッ.ン？()` | 要素数 |
| `プルャッ.ヤハ(値)` | 末尾に足す |
| `プルャッ.イヤッ(値)` | 最初に見つかった 1 つを消す |
| `プルャッ.フゥン(関数)` | map |
| `プルャッ.ハァ？(関数)` | filter |
| `プルャッ.ウラ(関数, 初期値)` | reduce |
| `プルャッ.ツナグ(区切り)` | 文字列に連結 |
| `プルャッ.ナラベ()` | 並べ替えた新しい List |
| `プルャッ.アル？(値)` | 含むか |

```
ヤハ プルャッ = [ン・プ, ン・ル, ン・ャ, ン・プン]

イヤッハー(プルャッ.フゥン(フゥン(ヤハァ) => ヤハァ * ン・ル))
イヤッハー(プルャッ.ハァ？(フゥン(ヤハァ) => ヤハァ > ン・ル))
イヤッハー(プルャッ.ウラ(フゥン(ヤハァ, ヤハッ) => ヤハァ + ヤハッ, ン・ン))
```

### Map

```
ヤハ ウララァ = {
    "うさぎ": ン・プ,
    "ハチワレ": ン・ル
}

ウララァ["うさぎ"]            // 取り出す(無い鍵なら ……)
ウララァ.ハァ？("うさぎ")     // あるか
ウララァ.ヤハ("ちいかわ", ン・ャ)
ウララァ.イヤッ("うさぎ")
ウララァ.カギ()               // 鍵の一覧
ウララァ.ン？()               // 件数
```

### Tuple と分解代入

```
ヤハ プルャッ = (ン・プ, ン・ル, ン・ャ)

ヤハ (ヤハァ, ヤハッ) = (ン・プ, ン・ル)
```

## 10. 制御構造

ブロックは `ヤーッ` で開いて `ハァッ` で閉じます。

### if / else

`ウラ` は**前のブロックを閉じつつ次を開きます**。だから `ハァッ` は
構文全体の末尾に 1 つだけです。

```
ハァ？ ヤハァ > ン・プン ヤーッ

    イヤッハー("ワァ！")

ウラ ハァ？ ヤハァ > ン・プ ヤーッ

    イヤッハー("フゥン")

ウラ ヤーッ

    イヤッハー("……")

ハァッ
```

条件は `ヤハ？ッ`(Bool)でなければいけません。数値や文字列は条件になりません。

### while

```
ウ～ラ～ ヤハァ < ン・プルャ ヤーッ
    ヤハァ += ン・プ
ハァッ
```

`ウ～ラ～` の `～` は全角チルダ(U+FF5E)です。長音符 `ー` とは別の文字なので、
`ウーラー` と書いても while にはなりません。

### foreach

```
ツツウラウラ プルャッ -> ヤハァ ヤーッ
    イヤッハー(ヤハァ)
ハァッ
```

List・Tuple・String・Map を回せます。Map を回すと鍵が出てきます。

### break / continue

```
ウ～ラ～ ヤー ヤーッ

    ハァ？ ヤハァ == ン・プル ヤーッ
        ムリッ                    // break
    ハァッ

    ハァ？ ヤハァ % ン・ル == ン・ン ヤーッ
        イヤッ                    // continue
    ハァッ

ハァッ
```

## 11. 関数

```
フゥン フゥンッ(ヤハァ, ヤハッ) ヤーッ
    ハァーッ ヤハァ + ヤハッ
ハァッ

ヤハ プルャ = フゥンッ(ン・プ, ン・ル)
```

型を書くこともできます。

```
フゥン フゥンッ(ヤハァ: プルッ, ヤハッ: プルッ) -> プルッ ヤーッ
    ハァーッ ヤハァ + ヤハッ
ハァッ
```

`ハァーッ` が return です。値なしでも書けます。

```
ハァーッ
```

> `ハァーッ` は **同じ行にある式だけ** を戻り値とみなします。値を返さない
> `ハァーッ` の次の行に式があっても、巻き込まれません。

### 既定値と可変長引数

```
フゥン フゥーン(ヤハァ: プルッ, ヤハッ: プルッ = ン・ル) -> プルッ ヤーッ
    ハァーッ ヤハァ * ヤハッ
ハァッ

フゥーン(ン・ププ)          // 10
```

```
フゥン フゥン？(...ヤハァ) -> プルッ ヤーッ
    ヤハ ヤハッ = ン・ン
    ツツウラウラ ヤハァ -> ヤハァッ ヤーッ
        ヤハッ += ヤハァッ
    ハァッ
    ハァーッ ヤハッ
ハァッ

フゥン？(ン・プ, ン・ル, ン・ャ)      // 6
```

可変長引数は List として受け取ります。

### 無名関数とクロージャ

式ひとつなら `=>` で書けます。

```
ヤハ プルャ = フゥン(ヤハァ) => ヤハァ * ン・ル
```

ブロックにもできます。

```
ヤハ プルャ = フゥン(ヤハァ) ヤーッ
    ハァーッ ヤハァ * ン・ル
ハァッ
```

外側の変数を捕まえられます。

```
フゥン フゥンーッ() ヤーッ
    ヤハ ヤハァ = ン・ン
    ハァーッ フゥン() ヤーッ
        ヤハァ += ン・プ
        ハァーッ ヤハァ
    ハァッ
ハァッ

ヤハ ヤハーァ = フゥンーッ()
ヤハーァ()      // 1
ヤハーァ()      // 2
```

## 12. ユーザー定義型とメソッド

型は `こういうこと？` で宣言します。

```
こういうこと？ ウララ ヤーッ
    ヤハァ: ワァッ
    ヤハッ: プルッ
ハァッ
```

生成は名前つきでも順番でもできます。

```
ヤハ ウラァ = ウララ(ヤハァ = "うさぎ", ヤハッ = ン・ャ)
ヤハ ウラッ = ウララ("ハチワレ", ン・プ)
```

名前つきと順番は混ぜられません。名前つきのときは全部のフィールドが要ります。

フィールドの読み書きは `.` です。

```
イヤッハー(ウラァ.ヤハァ)
ウラァ.ヤハッ = ン・プン
```

メソッドは型名を前に置いて宣言します。

```
フゥン ウララ.フゥンッ() -> ワァッ ヤーッ
    ハァーッ "${ヤハァ} が ${ヤハッ} 匹"
ハァッ

イヤッハー(ウラァ.フゥンッ())
```

**メソッドの中ではフィールドを名前だけで書けます。** 自分自身を渡したいときは
`コレ` を使います。

```
フゥン ウララ.フゥンァ() -> ウララ ヤーッ
    ハァーッ コレ
ハァッ
```

## 13. match

分岐が多いときは `もしかして` を使います。

```
もしかして ヤハァ ヤーッ

    ってこと？ ン・プ =>
        イヤッハー("ワァ")

    ってこと？ ン・ル =>
        イヤッハー("フゥン")

    じゃないってこと？ =>
        イヤッハー("……")

ハァッ
```

腕が複数文になるならブロックにします。

```
    ってこと？ ン・プ => ヤーッ
        イヤッハー("ワァ")
        イヤッハー("ワァ")
    ハァッ
```

パターンは値の比較です。`じゃないってこと？` は省略できます。

## 14. 例外と Result

### 投げる・捕まえる

```
なんとかなれーッ ヤーッ

    ワァーッ！("なんかダメ")

ダメだった… -> ヤハッ ヤーッ

    イヤッハー("つかまえた: ${ヤハッ}")

ハァッ
```

`ダメだった…` も `ウラ` と同じで前のブロックを閉じつつ次を開くので、
`ハァッ` は最後に 1 つだけです。受け取る名前(`-> ヤハッ`)は省略できます。

ゼロ除算や範囲外アクセスのような組み込みの実行時エラーも、同じように
`ダメだった…` で捕まえられます。

### Result

失敗しうる処理は Result を返します。成功が `ヤッター`、失敗が `ワァ…` です。

```
フゥン フゥンッ(ヤハァ: プルッ) ヤーッ
    ハァ？ ヤハァ == ン・ン ヤーッ
        ハァーッ ワァ…("ゼロはダメだった…")
    ハァッ
    ハァーッ ヤッター(ン・プルル / ヤハァ)
ハァッ
```

受け取り方は 3 とおりです。

```
ヤハ プルャ = フゥンッ(ン・プン)

プルャ.ヤッタ？()               // 成功したか(Bool)
プルャ.フゥン()                 // 中身を取り出す(失敗なら失敗理由)
プルャ.なんとかなれーッ！()     // 中身を取り出す。失敗なら例外を投げる
```

**`.なんとかなれーッ！()` の失敗は例外の送出と同じです。** つまり
`ダメだった…` で捕まえられます。

```
なんとかなれーッ ヤーッ

    ヤハ ヤハァ = プスン.フゥン("data.txt").なんとかなれーッ！()
    イヤッハー(ヤハァ)

ダメだった… -> ヤハッ ヤーッ

    イヤッハー("ワァ……")
    イヤッハー(ヤハッ)

ハァッ
```

どこでも捕まらずに一番外まで来たときだけ、`E3006 UncaughtException` として
表示され、終了コードは 3 になります。

## 15. モジュール

### 標準モジュール

文字列を付けずに書くと標準モジュールです。

```
これって… プスン
これって… プルャ

ヤハ ヤハァ = プスン.フゥン("data.txt").なんとかなれーッ！()
ヤハ ヤハッ = プルャ.フゥン(ヤハァ).なんとかなれーッ！()
```

| モジュール | 用途 |
|---|---|
| `プスン` | ファイル |
| `プルャ` | JSON |
| `プルャウラウラ` | HTTP |
| `ウロル` | 環境変数・CLI 引数・終了 |
| `フゥ～ンフゥン` | 時刻 |
| `ウラーヤッハ` | 乱数 |

操作語はモジュールをまたいで共通です。

| 語 | 意味 |
|---|---|
| `フゥン` | 取得・読込・変換 |
| `ヤハ` | 設定・追加・書込 |
| `ハァ？` | 確認・問い合わせ |
| `イヤッ` | 削除・破棄 |
| `イヤッハー` | 文字列化・外部化 |
| `ン？` | 件数・サイズ |

### 自分のモジュール

ファイル 1 つが 1 モジュールです。文字列でパスを書きます。

```
これって… "lib.ura"
これって… "lib.ura" -> プルャッ      // 別名を付ける
```

別名を付けないと、ファイル名(拡張子なし)がそのまま名前になります。

外へ出したいものには `ヤッハーヤーハー` を付けます。付いていないものは
そのファイルの中だけで見えます。

```
// lib.ura
ヤッハーヤーハー ヤハ！ プルャハ = ン・プルャ

ヤッハーヤーハー フゥン フゥンッ(ヤハァ: プルッ) -> プルッ ヤーッ
    ハァーッ ヤハァ * ン・ル
ハァッ

ヤッハーヤーハー こういうこと？ ウララ ヤーッ
    ヤハァ: ワァッ
ハァッ

フゥン フゥンァ() ヤーッ      // これは外から見えない
    ハァーッ "ないしょ"
ハァッ
```

```
// main.ura
これって… "lib.ura" -> プルャッ

イヤッハー(プルャッ.プルャハ)
イヤッハー(プルャッ.フゥンッ(ン・ププ))
ヤハ ヤハァ = プルャッ.ウララ(ヤハァ = "うさぎ")
```

### CLI 引数

```
これって… ウロル

ツツウラウラ ウロル.プルャ -> ヤハァ ヤーッ
    イヤッハー(ヤハァ)
ハァッ
```

```bash
urayaha run main.ura -- ワァ フゥン
```

`--` より後ろがプログラムへ渡ります。

## 16. 命名の慣習

URAYAHA には公式の「鳴き声命名慣習」があります。名前そのものからは意味が
読み取れないので、定義位置・型・引数・コメントから理解することを想定しています。
ここがこの言語のジョークの中心です。

| 用途 | 例 |
|---|---|
| ローカル変数 | `ヤハァ` `ヤハッ` `ヤハァッ` `ヤハー` |
| 関数 | `フゥンッ` `フゥンァ` `フゥーン` `フゥン？` |
| 定数 | `プルャ` `プルャッ` `プルャァ` |
| 型 | `ウララ` `ウラァ` `ウララァ` |

`response` や `合計` のような普通の名前も**合法です**。半分ジョーク・半分実用
という立ち位置を守るため、通常モードでは許しています。ただし Usagi らしさを
損なうので推奨はしません。

読みづらさは IDE と `urayaha dump --types` で補う想定です。

```bash
urayaha dump --types main.ura
```

```
フゥンッ : (プルッ, プルッ) -> プルッ
プルャッ : ムレッ<プルッ>
```

## 17. Strict Mode

うさぎ語らしさを強制したいときに使います。

```bash
urayaha check --strict-usagi main.ura
```

このモードでは、アラビア数字リテラルのような「普通に喋っている」書き方が
警告ではなくエラーになります。

```
フゥン…

「10」って普通に喋ってない？(うさぎ数字だと「ン・ルル」)
```

通常モードではアラビア数字も書けます。実務で急いでいるときの逃げ道です。

## 18. つまずきやすいところ

### 数値に `ン・` を付け忘れる

```
ヤハ ヤハァ = プルャ        // 27 ではなく、変数 プルャ を読もうとする
ヤハ ヤハァ = ン・プルャ    // これが 27
```

### `ハァッ` を書きすぎる

`ウラ` と `ダメだった…` は前のブロックを閉じます。`ハァッ` は構文の最後に
1 つだけです。

```
// 間違い
ハァ？ ヤー ヤーッ
    イヤッハー("ワァ")
ハァッ
ウラ ヤーッ
    イヤッハー("フゥン")
ハァッ

// 正しい
ハァ？ ヤー ヤーッ
    イヤッハー("ワァ")
ウラ ヤーッ
    イヤッハー("フゥン")
ハァッ
```

### 語のあいだの空白を落とす

```
ウラウラ        // 識別子 1 つ
ウラ ウラ       // else が 2 つ
ウ～ラ～        // while
```

### `～` と `ー` を取り違える

`ウ～ラ～`(while)の `～` は全角チルダです。`ウーラー` は別の語で、
ただの識別子になります。整形器もこの 2 つを取り違えません。

### `.ン？` に括弧を付け忘れる

要素数はメソッド呼び出しです。

```
プルャッ.ン？()       // 正しい
プルャッ.ン？         // 関数そのものが返る
```

### Result をそのまま使う

標準ライブラリの失敗しうる関数は Result を返します。中身が欲しいときは
取り出しが要ります。

```
ヤハ ヤハァ = プスン.フゥン("data.txt")                     // Result
ヤハ ヤハッ = プスン.フゥン("data.txt").なんとかなれーッ！()  // 中身
```

### 全角と半角の `！` `？`

`！`/`？` は `!`/`?` に正規化されるので、`ハァ？` と `ハァ?` はまったく同じです。
好きなほうで書けます。一方 `～ ー … ・ ッ ァ` は正規化されないので、
書いたとおりに区別されます。
