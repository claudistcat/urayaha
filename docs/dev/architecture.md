# 処理系の構造

```
main.ura
   ↓  lexer.py       字句解析
Token 列
   ↓  parser.py      構文解析
AST                  ast_nodes.py
   ↓  checker.py     名前解決 + 型検査
   ↓  compiler.py    バイトコード生成
FuncProto
   ↓  vm.py          スタックマシン
```

`runtime.py` がこの流れを駆動し、`cli.py` がコマンドとして包みます。

表面構文のジョーク性は VM や IR には持ち込みません。命令名は `LOAD_CONST` や
`JUMP_IF_FALSE` のような普通の英語です。

---

## lexer.py

3 つの規則が絡みます。

### 正規化

`！`→`!`、`？`→`?` だけを、**語を走査するときにのみ** 適用します。

前処理として一括で掛けてはいけません。文字列リテラルの中身まで書き換わり、
`イヤッハー("ワァ！")` の出力が変わってしまいます。NFKC を丸ごと掛けるのも
だめで、NFKC は `…`(U+2026)を `...` へ展開するため NULL(`……`)が可変長引数
(`...`)と衝突します。

`～ ー … ・ ッ ァ ィ ゥ ェ ォ ャ ュ ョ` は発話の一部なので触りません。

### うさぎ数字

数値リテラルは `ン・` プレフィックス必須です。`ン` と `・` が並んだところで
数値として読み始めます。プレフィックスの無い `プルャ` は識別子です。

`_lex_urayaha_number` が整数部と(あれば)小数部を 4 進で読みます。小数点は
`.` の次が数字文字のときだけ小数点として扱うので、`ン・プ.フゥン()` は
メンバアクセスになります。

### バックトラック付き最長一致

`_resolve_word` の仕事です。

1. 語中文字(`? ! … ～` を含む)を最大長で読む
2. それが既知語ならそのまま採用(`ヤハ?ッ` → Bool、`ハァ?` → IF)
3. 既知語でなければ、`?` `!` を末尾 1 文字だけ取り込む。ただし直後が
   `? . = !` のときは演算子(`??` `?.` `!=`)なので取り込まない
4. 自然な語境界より長い既知語が前方一致するなら、そちらを優先

これで次のように割れます。

| 入力 | 結果 |
|---|---|
| `ヤハ?ッ` | Bool 型 1 語 |
| `プルッ?` | 識別子 `プルッ?`(Parser が型位置で `?` を Optional として切る) |
| `ヤハァ??ヤハッ` | `ヤハァ` + `??` + `ヤハッ` |
| `ヤハァ?.フゥン` | `ヤハァ` + `?.` + `フゥン` |
| `フゥン?` | 識別子(ユーザー定義の関数名として使える) |

語トークンどうしのあいだには空白が必要です。空白が無いと `ヤハヤハァ` が
`ヤハ ヤハァ` なのか識別子なのか決まりません。

## parser.py

再帰下降です。特徴は 3 つあります。

### チェーンブロック

`ウラ`(else)と `ダメだった…`(catch)は、**前のブロックを閉じつつ次を開きます**。
`ハァッ` は構文全体の末尾に 1 つだけです。

```
ハァ？ 条件 ヤーッ
    ...
ウラ ヤーッ
    ...
ハァッ
```

`_body_until(*stop_kinds)` が終端キーワードを消費せずに宣言を読み、
`_if_statement` / `_try_statement` が次の節へ繋ぎます。

### 改行はただの空白

改行に文法的な意味はありません。ただし `_return_statement` だけは、
**同じ行にある式** しか戻り値とみなしません。そうしないと値を返さない
`ハァーッ` が次の行の式を巻き込みます。

### メンバ位置の予約語

`_member_name` は `.` の直後で予約語トークンをそのまま名前として受けます。
`プスン.ヤハ` の `ヤハ` は LET トークンとして届きますが、メンバ名に読み替えます。

---

## checker.py

名前解決と型検査を 1 パスでやります。

型は `Type(name, args, optional, info)` です。関数型は `info` に
`(params, ret, min_args, max_args)`、構造体は `info` にフィールドの
`[(名前, 型)]` を持ちます。

方針は **「確実に間違っているものだけを落とす」** です。推論できないところは
`ナンカッ`(Any)へ落として通します。`assignable()` は判断できないとき True を
返します。ここで誤検知を出すと、まともに書けない言語になります。

引数の個数は検査しますが、引数ひとつひとつの型は検査していません。

### 2 つのメソッド表

組み込み型のメソッドは `stdlib.py`(実行時の実体)と `checker.py`(戻り値の型)の
2 か所にあります。ずれても誤検知しないよう、`_runtime_members()` が
「型は分からないが実行時には在る」名前を逃がします。それでも両方に書いてください。

### REPL

REPL は入力ごとに別コンパイルなので、`repl_state` に宣言を積み上げて
次の入力へ持ち越します。このモードでは未使用警告を出さず、グローバルの
再宣言も許します。

---

## compiler.py

AST をバイトコードにします。

### ローカルはすべて Cell

`Frame.locals` は `Cell` の配列です。クロージャの捕捉は「親フレームの Cell を
そのまま持つ」だけになり、どのローカルが捕捉されるかの解析が要りません。

代償として、ループ本体で作ったクロージャは反復ごとではなくループ変数の Cell を
共有します(JavaScript の `var` と同じ)。

### 既定値引数

VM は渡されなかった引数に `MISSING` 番兵を入れます。関数本体の先頭に

```
LOAD_LOCAL slot
JUMP_IF_SET skip
<既定値の式>
STORE_LOCAL slot
skip:
```

を生成するので、既定値は関数自身のスコープで評価されます。先行する引数を
参照できます。

### 名前つき生成

`ウララ(ヤハァ = "うさぎ")` は、その型がコンパイル時に分かるなら `MAKE_STRUCT`
に落ちます。別モジュールから来た型のように実行時にしか分からない場合は
`CALL_KW` を出し、VM が `_construct_named` で組み立てます。

### メソッド内のフィールド

`current_recv` が立っているあいだ、ローカルにも引数にも無い名前がレシーバの
フィールド名と一致すれば `コレ.フィールド` へ読み替えます。

## vm.py

スタックマシンです。フレームごとに自分のスタックを持ちます。

### 再入

`VM.run()` の底は 0 固定ではなく「いま積まれているフレーム数」です。
import はネイティブ関数の中から `run()` を再入するので、0 固定にすると
モジュールの実行が終わったあとに呼び出し元のフレームまで巻き込んで
走り続けてしまいます。

同じ理由で、ネイティブ関数から Urayaha の関数を呼ぶ `call_value()` も
現在のフレーム数を底にします。List の `フゥン`(map)がラムダを呼ぶ経路です。

### 例外

`SETUP_TRY` がハンドラ `(飛び先, そのときのスタック高)` をフレームに積みます。
`UrayahaRuntimeError` が飛ぶと `_unwind` がフレームを遡ってハンドラを探し、
スタックを記録した高さまで削ってから例外値を積み直します。

`ワァーッ！` の送出と `Err` の unwrap は同じ経路です。どこでも捕まらずに
一番外まで来たときだけ `E3006 UncaughtException` になります。

---

## stdlib.py

標準モジュールは `Namespace` です。`これって… プスン` は `runtime.py` の
`__これって__` ネイティブ関数を呼び、標準モジュール表から返します。
文字列を渡した場合はファイルを読み、`ヤッハーヤーハー` 付きの宣言だけを
`Module.exports` に入れて返します。

予測できる失敗は例外ではなく Result を返します。

---

## fmt.py

段の数え方を 3 つ足し合わせます。

* ブロック段 — `ヤーッ` で深くなり `ハァッ` で浅くなる。`ウラ` と `ダメだった…`
  はその行だけ 1 段戻して出し、段の総数は変えない
* 括弧段 — `( [ {` で深くなる。複数行の Map リテラルや引数並びが行頭に
  貼りつくのを防ぐ
* match の腕 — `=>` で終わる行の次の行を 1 段深くする

**字句は一切書き換えません。** `～ ー … ッ ァ` を別の文字に置き換えると
`ウ～ラ～` が while でなくなります。

---

## cli.py

うさぎ語 alias は引数解析の段階で英語コマンドへ正規化します(`ALIASES`)。
alias と英語コマンドで挙動が変わってはいけません。

`build` は `pickle` で `.urab` を書きます。マジック文字列と形式バージョンを
先頭に入れて、合わないものは実行を拒否します。pickle なので、信頼できない
`.urab` を実行してはいけません。
