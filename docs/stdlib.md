# 標準ライブラリ

標準モジュールは `これって… プスン` のように、名前を文字列にせず読み込みます。その後は `プスン.フゥン("data.txt")` のようにメンバを呼びます。

表の引数数は、プログラムで括弧の中に書く引数の数です。`0～1` は省略できる引数が 1 個、`0～無制限` は何個でも渡せることを表します。戻り値の `……` は値がないことを表します。

Result は成功を `ヤッター(値)`、失敗を `ワァ…(理由)` として保持します。`.ヤッタ?()` で成功か調べ、`.フゥン()` で成功値または失敗理由を取り出せます。`.なんとかなれーッ！()` は成功値を取り出し、失敗なら例外を送出します。詳しくは末尾の Result の表を参照してください。

以下の例は各コードを `.ura` ファイルに保存し、`python -m urayaha run ファイル名.ura` で実行できます。Windows の PowerShell では、先に次を実行してください。数値の出力例は `--human-number` を付けない場合です。

```powershell
$env:PYTHONIOENCODING = 'utf-8'
```

## プスン — ファイル

```urayaha
これって… プスン
```

相対パスは実行時の作業ディレクトリを基準にします。

| メンバ | 引数数・引数 | 戻り値 | Result |
|---|---|---|---|
| `フゥン` | 1：パス文字列 | UTF-8 で読んだファイル全体の文字列です。入出力に失敗すると理由の文字列を保持します。 | はい |
| `ヤハ` | 2：パス文字列、書く値 | 値の表示用文字列を UTF-8 で上書きし、成功値は `……` です。入出力に失敗すると理由を保持します。 | はい |
| `ハァ?` | 1：パス文字列 | ファイルまたはディレクトリが存在すれば `ヤー`、なければ `イヤ` です。 | いいえ |
| `イヤッ` | 1：パス文字列 | ファイルを削除し、成功値は `……` です。削除できなければ理由を保持します。ディレクトリ削除用ではありません。 | はい |
| `ツツウラウラ` | 0～1：ディレクトリのパス文字列。省略時は `"."` です。 | 直下の名前をソートした List です。再帰的には探索しません。失敗すると理由を保持します。 | はい |

`ヤハ` は改行を自動で付けません。既存ファイルは切り詰め、親ディレクトリは作りません。文字列以外は `イヤッハー` と同じ表記になり、数値表記は `--human-number` の影響を受けます。`フゥン` の UTF-8 デコード失敗は失敗 Result にはなりません。

次の例は、書き込み可能な作業ディレクトリで実行してください。`stdlib-message.txt` を作成して削除するので、その名前の既存ファイルがない場所を使います。

```urayaha
これって… プスン
プスン.ヤハ("stdlib-message.txt", "こんにちは").なんとかなれーッ！()
イヤッハー(プスン.フゥン("stdlib-message.txt").なんとかなれーッ！())
イヤッハー(プスン.ハァ?("stdlib-message.txt"))
プスン.イヤッ("stdlib-message.txt").なんとかなれーッ！()
```

出力は次のとおりです。

```text
こんにちは
ヤー
```

## プルャ — JSON

```urayaha
これって… プルャ
```

| メンバ | 引数数・引数 | 戻り値 | Result |
|---|---|---|---|
| `フゥン` | 1：JSON 文字列 | JSON を読み取った値です。オブジェクトは Map、配列は List、文字列・数値・真偽値は対応する値、`null` は `……` です。失敗すると理由を保持します。 | はい |
| `イヤッハー` | 1：JSON にする値 | JSON 文字列です。失敗すると理由を保持します。 | はい |

構造体はフィールド名をキーにしたオブジェクトになり、内側の構造体も変換されます。タプルは配列になります。日本語は Unicode エスケープにせず、そのまま出力します。JSON の数値は 10 進であり、`--human-number` に左右されません。

```urayaha
これって… プルャ
ヤハ ヤハァ = プルャ.フゥン("[1, 2, 3]").なんとかなれーッ！()
イヤッハー(ヤハァ)
イヤッハー(プルャ.イヤッハー(ヤハァ).なんとかなれーッ！())
```

```text
[ン・プ, ン・ル, ン・ャ]
[1, 2, 3]
```

## プルャウラウラ — HTTP

```urayaha
これって… プルャウラウラ
```

| メンバ | 引数数・引数 | 戻り値 | Result |
|---|---|---|---|
| `フゥン` | 1：URL 文字列 | GET のレスポンス本文の文字列です。通信などに失敗すると理由を保持します。 | はい |
| `ヤハ` | 1～2：URL 文字列、本文。本文は省略可能です。 | POST のレスポンス本文の文字列です。通信などに失敗すると理由を保持します。 | はい |
| `ハァ?` | 1：URL 文字列 | GET が成功すれば `ヤー`、例外が発生すれば `イヤ` です。 | いいえ |

POST の本文に Map または List を渡すと JSON にして送信し、`Content-Type` は `application/json; charset=utf-8` になります。文字列または本文省略時は `text/plain; charset=utf-8` で、省略時の本文は空です。数値や構造体を直接本文に渡す用途には対応していません。本文の変換中に起きた例外は失敗 Result にはなりません。

通信のタイムアウト指定は 30 秒で、`User-Agent` は `urayaha/0.4` です。レスポンス本文は UTF-8 として読み、不正なバイトは置換文字になります。ステータスやレスポンスヘッダーは返しません。`ハァ?` も実際に GET を行うため、接続の確認だけで済む操作ではありません。

次の例には HTTP 接続が必要です。`http://127.0.0.1:8765/` で本文 `こんにちは` を返すローカルサーバーを用意した状態で実行確認しました。自分のサーバーを使う場合は URL を置き換えてください。接続できなくても unwrap せず、失敗理由を表示します。

```urayaha
これって… プルャウラウラ
ヤハ ヤハァ = プルャウラウラ.フゥン("http://127.0.0.1:8765/")
イヤッハー(ヤハァ.ヤッタ?())
イヤッハー(ヤハァ.フゥン())
```

```text
ヤー
こんにちは
```

## ウロル — OS

```urayaha
これって… ウロル
```

| メンバ | 引数数・引数 | 戻り値・内容 | Result |
|---|---|---|---|
| `フゥン` | 1：環境変数名の文字列 | 環境変数の文字列です。未設定なら `……` です。 | いいえ |
| `プルャ` | 呼び出さず、値として参照します。 | プログラムに渡された引数の文字列 List です。 | いいえ |
| `イヤッ` | 0～1：終了コードの整数。省略時は 0 です。 | プログラムを終了するため、戻りません。 | いいえ |

`プルャ` にスクリプトのファイル名は含みません。CLI の `--` より後ろをそのまま受け取ります。

```urayaha
これって… ウロル
イヤッハー(ウロル.フゥン("PYTHONIOENCODING"))
イヤッハー(ウロル.プルャ)
ウロル.イヤッ()
```

`os.ura` に保存し、`python -m urayaha run os.ura -- りんご --sample` で実行したときの出力です。終了コードは 0 です。

```text
utf-8
[りんご, --sample]
```

## フゥ～ンフゥン — 時刻

```urayaha
これって… フゥ～ンフゥン
```

| メンバ | 引数数・引数 | 戻り値 | Result |
|---|---|---|---|
| `フゥン` | 0 | 現在の Unix 時刻を秒単位の整数で返します。小数部分は切り捨てます。 | いいえ |
| `ウ～ラ～` | 1：待機する秒数。整数または小数です。 | 指定した秒数だけ実行を待機させ、`……` を返します。 | いいえ |

待機時間には 0 以上の数値を渡します。負の値などによる待機失敗は Result にはなりません。

```urayaha
これって… フゥ～ンフゥン
イヤッハー(フゥ～ンフゥン.フゥン() > ン・ン)
フゥ～ンフゥン.ウ～ラ～(ン・ン)
イヤッハー("待機しました")
```

```text
ヤー
待機しました
```

## ウラーヤッハ — 乱数

```urayaha
これって… ウラーヤッハ
```

| メンバ | 引数数・引数 | 戻り値 | Result |
|---|---|---|---|
| `フゥン` | 登録上は 0～2。使える形は引数なし、または下限・上限の整数 2 個です。 | 引数なしなら 0 以上 1 未満の Float、2 引数なら両端を含む範囲のランダムな Int です。 | いいえ |

上下限が整数でなければ `E2001`、上限が下限より小さければ `E2002` になります。引数は 0 個か 2 個です。1 個で呼ぶと `E2003` になります。

```urayaha
これって… ウラーヤッハ
イヤッハー(ウラーヤッハ.フゥン(ン・プ, ン・プ))
ヤハ ヤハァ = ウラーヤッハ.フゥン()
イヤッハー(ヤハァ >= ン・ン)
イヤッハー(ヤハァ < ン・プ)
```

```text
ン・プ
ヤー
ヤー
```

## 読み込みなしで使える組み込み関数

以下の関数は、どれも Result を返しません。

| 関数 | 引数数・引数 | 動作と戻り値 |
|---|---|---|
| `イヤッハー` | 0～無制限：表示する値 | 各値を空白で区切って標準出力へ書き、最後に改行します。`……` を返します。引数なしなら改行だけを書きます。 |
| `イヤッハー…` | 0～無制限：表示する値 | 各値を空白で区切って標準出力へ書き、改行せずに出力をフラッシュします。`……` を返します。 |
| `ワァ?` | 0 | 標準入力から 1 行を読み、末尾の LF と CR を除いた文字列を返します。入力終了なら `……` です。空行は空文字列です。 |
| `プルッ` | 1：整数・小数・真偽値・数値文字列 | Int に変換します。小数は 0 に向かって切り捨て、真偽値は 1 または 0 にします。変換できない値は `E2001` です。 |
| `プルァッ` | 1：整数・小数・真偽値・数値文字列 | Float に変換します。真偽値は 1.0 または 0.0 になります。変換できない値は `E2001` です。 |
| `ワァッ` | 1：任意の値 | `イヤッハー` と同じ表示用の文字列に変換します。文字列はそのままです。 |
| `ヤハ?ッ` | 1：任意の値 | `イヤ` と `……` だけを `イヤ` にし、それ以外は `ヤー` にします。0、空文字列、空の List や Map も `ヤー` です。 |

数値変換では文字列の前後の空白を取り除き、10 進表記または `"ン・プルャ"` のようなうさぎ数字の整数表記を受け取ります。うさぎ数字の文字列に小数点は使えません。`プルッ("1.5")` は整数に変換できませんが、`プルァッ("1.5")` は変換できます。現状では `"ン・"` だけでも 0 に変換されます。

表示用の数値は通常うさぎ数字になり、`--human-number` を指定すると 10 進になります。これは出力だけでなく、`ワァッ`、ファイル書き込み、後述の `ツナグ` にも適用されます。真偽値は `ヤー` / `イヤ`、値なしは `……` と表示します。List や Map の中の文字列にも引用符を付けないため、表示用の文字列は JSON ではありません。

## 組み込み型のメソッド

`値.メソッド(引数)` の形で呼びます。表の「受け手」はドットの左側です。受け手は括弧内の引数数に含めません。例えば List の `ヤハ` は `ヤハァ.ヤハ(値)` のように 1 引数です。

### List

いずれも Result を返しません。

| メソッド | 受け手 | 引数数・引数 | 戻り値・動作 |
|---|---|---|---|
| `ン?` | List | 0 | 要素数の Int です。 |
| `ヤハ` | List | 1：追加する値 | 末尾に追加し、`……` を返します。元の List を変更します。 |
| `イヤッ` | List | 1：削除する値 | 最初に一致した要素を削除し、`……` を返します。存在しなければ何もしません。添字による削除ではありません。 |
| `フゥン` | List | 1：1 引数の関数 | 各要素を関数に渡した結果から、新しい List を作ります。 |
| `ハァ?` | List | 1：1 引数の関数 | 関数の戻り値が真と判定される要素だけの新しい List です。真偽の判定は `ヤハ?ッ` と同じです。 |
| `ウラ` | List | 1～2：2 引数の関数、初期値 | 累積値と各要素を順に関数へ渡し、最後の累積値を返します。初期値省略時は `……` です。空の List なら初期値をそのまま返します。 |
| `ツナグ` | List | 0～1：区切り文字列。省略時は `""` です。 | 各要素を表示用文字列にして結合した String です。 |
| `ナラベ` | List | 0 | 昇順に並べた新しい List です。元の List は変更しません。比較できない値の混在は `E2002` です。 |
| `アル?` | List | 1：探す値 | 一致する要素があれば `ヤー`、なければ `イヤ` です。 |

`フゥン`、`ハァ?`、`ウラ` は、処理を始める時点で要素の並びをコピーしてから順に処理します。`ウラ` は初期値を省略しても先頭要素を初期値にせず、最初の呼び出しにも `……` と先頭要素を渡します。

タプルにも同じメソッドが見つかりますが、`ヤハ` と `イヤッ` はタプルを変更できず、現状では Python の例外になります。これらの変更操作は List に使ってください。

### Map

いずれも Result を返しません。

| メソッド | 受け手 | 引数数・引数 | 戻り値・動作 |
|---|---|---|---|
| `ン?` | Map | 0 | キーの数の Int です。 |
| `ハァ?` | Map | 1：キー | キーが存在すれば `ヤー`、なければ `イヤ` です。 |
| `ヤハ` | Map | 2：キー、値 | キーに値を設定し、`……` を返します。既存のキーなら上書きします。 |
| `イヤッ` | Map | 1：キー | キーと値を削除し、`……` を返します。キーがなければ何もしません。 |
| `カギ` | Map | 0 | キーの新しい List です。Map の保持する順序で返し、ソートしません。 |

### String

いずれも Result を返しません。

| メソッド | 受け手 | 引数数・引数 | 戻り値・動作 |
|---|---|---|---|
| `ン?` | String | 0 | Unicode コードポイント数の Int です。バイト数ではありません。 |
| `ワケ` | String | 0～1：区切り文字列 | 区切りで分割した文字列の List です。区切りを省略するか空文字列にすると、1 コードポイントずつ分けます。 |
| `ハァ?` | String | 1：部分文字列 | 含まれていれば `ヤー`、いなければ `イヤ` です。 |
| `ツナグ` | 区切りの String | 1：要素の List | 各要素を表示用文字列にし、受け手を区切りにして結合した String です。タプルなど反復できる値も受け付けます。 |

`"a b".ワケ()` は空白で単語に分けず、`[a,  , b]` になります。`"a,,b".ワケ(",")` のように区切りを明示した場合は空の部分も残します。

### Result

以下は Result を操作するメソッドです。成功値そのものが Result なら取り出した値も Result ですが、新しい Result で包み直しません。

| メソッド | 受け手 | 引数数・引数 | 戻り値・動作 |
|---|---|---|---|
| `なんとかなれーッ！` | Result | 0 | 成功なら成功値を返します。失敗なら失敗値を例外として送出します。 |
| `ヤッタ?` | Result | 0 | 成功なら `ヤー`、失敗なら `イヤ` です。 |
| `フゥン` | Result | 0 | 成否に関係なく、保持している値をそのまま返します。失敗なら理由を返し、例外にはしません。 |

メソッド名の全角 `！` は半角 `!` と同じように使えます。失敗 Result の `.なんとかなれーッ！()` は `ワァーッ！(...)` と同じく `ダメだった…` で捕捉できます。捕捉されずに外まで出た場合だけ `E3006 UncaughtException` が表示されます。[診断リファレンス](errors.md)も参照してください。

<!-- 要確認 -->

- 乱数の `フゥン` は引数 0 個か 2 個です。1 個で呼ぶと E2003 になります。
- ファイル読み込みは、開けない場合と UTF-8 として読めない場合の両方を Result の失敗にします。HTTP POST の本文変換は通信の例外捕捉より前に行われるので、変換自体が失敗すると Result ではなく実行時エラーになります。
- タプルには読むだけのメンバ(`ン?` `フゥン` `ハァ?` `ウラ` `ツナグ` `ナラベ` `アル?`)だけが生えています。中身を変える `ヤハ` と `イヤッ` はありません。
